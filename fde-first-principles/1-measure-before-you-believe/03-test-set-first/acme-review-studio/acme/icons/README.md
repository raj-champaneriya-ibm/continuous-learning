# Material icons

Official Google Material Design Icons (filled, 24px), the artwork also used by MUI Icons.
Source: https://github.com/google/material-design-icons/tree/master/src
License: Apache-2.0; full license in LICENSE.

Local filenames: review = action/assignment_turned_in; play = av/play_arrow;
cases = action/view_list; knowledge = maps/menu_book; score = editor/bar_chart;
settings = action/settings; save = content/save; check, close, arrow_back (back),
arrow_forward (next) = navigation category.

SVGs are bundled and inlined with currentColor and decorative accessibility attributes.
No React, font service, or runtime icon network requests required.
